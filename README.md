# World Smith (HoI4 Map Architect)

World Smith は、Hearts of Iron IV (HoI4) 用の高性能かつベクターファーストなマップ編集ツールです。
「手描きの煩雑さ」を排除し、ヘックスベースの画一的なプロヴィンス形状によるマップ生成から、範囲選択による一括ステート・地形設定など、Mod制作の根幹を強力にサポートします。

## 📥 一般ユーザー向けの実行方法 (最も簡単な方法)

World Smith を使うにあたって、プログラミングや環境構築の知識は必要ありません。

1. GitHub の右側にある **Releases** ページを開きます。
2. 最新のリリースから、お使いのOSに合ったファイル（Windowsなら `world_smith-windows-x86_64.zip`）をダウンロードします。
3. ダウンロードした ZIP ファイルを展開（解凍）します。
4. フォルダ内にある `world_smith.exe` をダブルクリックして起動します。

## 🛠 開発・テストの流れ (自律チェックとCI/CD)

このリポジトリは、GitHub Actions による自動テスト (CI) と自動リリース (CD) を備えています。

### コミットとPRベースの協業スタイル

AIにコードを変更させる際の最も安全でスムーズな方法は、**Pull Request (PR) を介したレビュー・マージ**です。

1. **指示**: AI に「〇〇の機能を実装して」と指示を出します。
2. **実装**: AI がコードを書き、ローカルでテストを通します。
3. **PR作成**: AI が `submit` を実行し、変更を別ブランチにコミットして Pull Request を作成します。
4. **CIチェック**: PR が作成されると、GitHub Actions が自動で裏側でコンパイルとテストを実行し、エラーがないかを確認します。
5. **承認とマージ**: GitHubの画面からPRの内容と自動テストの結果を確認し、問題なければマージボタンを押します。

### 新しいリリースの公開方法 (バイナリの配布)

新しい機能がまとまり、ユーザーに最新版を配りたくなった場合は、GitHub上で「タグ（Tag）」を作成してPushするだけで、あとは自動でシステムがバイナリを作成してくれます。

GitHub の Releases ページから「Draft a new release」ボタンを押し、新しいタグ名（例: `v0.2.0`）を入力して公開することで自動ビルドが走ります。

## 💻 開発環境の構築 (開発者向け)

Rust がインストールされている環境で、以下のコマンドで手動ビルド・テストが可能です。

- 実行: `cargo run --release`
- テスト: `cargo test`
- Linter: `cargo clippy`

Linux 環境でビルドする場合は依存ライブラリが必要です。
